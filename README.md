## 1. סקירת הפרויקט (Project Overview)

**SocialMirror-AI** הינו פרויקט אקדמי מכין המציע פלטפורמת מחקר והתערבות מבוססת חברת סוכני בינה מלאכותית (Multi-Agent System). הפלטפורמה מתוכננת לחקור, למדל ולמתן את ההשפעות השליליות של פידים אלגוריתמיים ברשתות חברתיות (כגון Instagram ו-TikTok) על רווחתם הנפשית של צעירים בגילאי 15–26.

הפרויקט מתמקד במוקדים המחקריים הבאים:
1. **שיבוש אלגוריתמי והשוואה חברתית כלפי מעלה (Upward Social Comparison)**: ניתוח המנגנון לפיו מנועי המלצה ממקסמי מעורבות (Engagement-Maximizing Algorithms) חושפים משתמשים באופן מוטה לתכנים אידיאליים ומלוטשים, המעוררים אפקט ניגוד ושחיקה בערך העצמי.
2. **הפרדת מבנים מתודולוגית (Construct Disaggregation)**: מעבר ממדידה גולמית ועיוורת של "זמן מסך" (אשר לפי סקרי SCA מסביר פחות מ־0.4% מהשונות) לניתוח סמנטי בזמן אמת של מיקרו-אירועי השוואה, אידיאליזציה ושיווק משפיענים סמוי.
3. **ארכיטקטורת חברת סוכנים מקומית (On-Device Edge MAS)**: תכנון ארבעה סוכני AI אוטונומיים הפועלים על גבי מכשיר הקצה תוך הגנת פרטיות מלאה וללא תלות בשרתי ענן מרכזיים.
4. **שיקוף מטא-קוגניטיבי מול כפייה פטרנליסטית**: מתן תובנות סוקרטיות ודחיפות עדינות (Nudges) המעצימות את האוטונומיה האישית של המשתמש וממזערות התנגדות פסיכולוגית (Reactance).

## 2. חלוקת תפקידי הסוכנים: סוכני עבודה מול סוכני המערכת המוצעת

בפרויקט קיימת הבחנה קטגורית חדה בין **סוכני זרימת העבודה (Workflow Agents)** שסייעו בכתיבת הדוח לבין **סוכני המערכת המוצעת (Proposed Platform Architecture)**:

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                    SocialMirror-AI Agent Classification Taxonomy                │
├─────────────────────────────────────────────────────────────────────────────────┤
│             1. סוכני העבודה שסייעו בהכנת הדוח (Workflow Meta-Agents)             │
│                      מוגדרים תחת תיקיית .agents/ במאגר                          │
├──────────────────────┬──────────────────────┬───────────────────┬───────────────┤
│ academic-coordinator │ academic-researcher  │  academic-writer  │ design-agent  │
├──────────────────────┴──────────────────────┴───────────────────┴───────────────┤
│             2. סוכני מערכת SocialMirror-AI העתידית (Proposed Platform)          │
│                       ארכיטקטורת חברת הסוכנים המוצעת לפיתוח עתידי               │
├──────────────────────┬──────────────────────┬───────────────────┬───────────────┤
│    ObserverAgent     │     AnalystAgent     │  ReflectorAgent   │InterventionAg.│
└──────────────────────┴──────────────────────┴───────────────────┴───────────────┘
```

### א. סוכני העבודה שסייעו בהכנת הדוח האקדמי (Workflow Agents)
ארבעה סוכני AI עצמאיים שהוגדרו תחת `.agents/` וסייעו לשמס ומלאק בתהליך המחקר, הכתיבה, הטיפוגרפיה והבדיקה של הדוח האקדמי:
1. **Academic Coordinator Agent (`academic-coordinator`)**: אמון על ניהול זרימת העבודה האקדמית, סנכרון שיתוף הפעולה ההדדי ללא חלוקת פרקים פנימית, פיקוח על תקציב העמודים (כ־40 עמודים) ואכיפת סטנדרטים מדעיים ומתודולוגיים.
2. **Academic Researcher Agent (`academic-researcher`)**: אמון על גילוי, אימות ובקרה מדעית של מקורות אמפיריים, ניתוח גודלי אפקט סטטיסטיים ($r, \beta, d$), הפרדה קפדנית בין קורלציה לסיבתיות, ואימות 30 מקורות BibTeX ו-DOIs.
3. **Academic Writer Agent (`academic-writer`)**: אמון על ניסוח מדעי אקדמי מדויק בעברית רהוטה ומינוח בינלאומי באנגלית, ביסוס מודלים מתמטיים של וקטור המצב הנפשי ($\mathbf{w}(t)$), והקפדה על בידול קטגורי בין ספרות קיימת לבין תכנון עתידי.
4. **Design & Typesetting Agent (`design-agent`)**: אמון על שפת העיצוב היוקרתית (SocialMirror Premium Theme) – עיצוב שער כהה חד-עמודי, עמודים פנימיים אלגנטיים, תרשימי זרימה וארכיטקטורה ב-TikZ, טבלאות booktabs, ואיזון טיפוגרפי דו-כיווני (RTL/LTR).

### ב. סוכני המערכת המוצעת של פלטפורמת SocialMirror-AI
ארבעת סוכני הבינה המלאכותית המתוכננים לפעול בארכיטקטורת המוצר העתידית:
1. **סוכן התצפית (`ObserverAgent`)**: קליטה פסיבית של מטא-נתונים מהפיד (זמני שהייה, תגיות, כיתוב ומעורבות), אנונימיזציה מקומית (SHA-256) וסינון רעשים.
2. **סוכן הניתוח (`AnalystAgent`)**: מודל שפה מקומי קומפקטי המסווג בזמן אמת את בולטות ההשוואה החברתית ($\comparisonScore \in [0, 1]$) ומדד החשיפה למשפיענים ולפרסום סמוי ($\exposureIndex \in [0, 1]$).
3. **סוכן הרפלקציה (`ReflectorAgent`)**: מנהל זיכרון אפיזודי המעדכן את וקטור המצב הנפשי הרציף ($\wellbeingVector{}(t)$) ומפיק תובנות מטא-קוגניטיביות סינתטיות.
4. **סוכן ההתערבות (`InterventionAgent`)**: הגשת שאלות סוקרטיות ודחיפות עדינות (Nudges) בנקודות שבירה טבעיות ללא ציווים פטרנליסטיים.

## 6. הוראות קומפילציה (Build Instructions)

הדוח עושה שימוש במנוע **XeLaTeX** עבור תמיכה מלאה בגופני Unicode של מערכת ההפעלה ובקרת כיווניות (Hebrew RTL עם מקטעי English LTR):

1. יש לוודא התקנת הפצת LaTeX עדכנית הכוללת מנוע XeLaTeX (כדוגמת **MiKTeX** על Windows או **TeX Live**).
2. פתיחת מסוף PowerShell בתיקיית `report/`:
   ```powershell
   cd report
   powershell -ExecutionPolicy Bypass -File compile.ps1
   ```
3. הסקריפט מריץ סדרת בנייה מלאה בת 4 שלבים:
   - `xelatex main.tex` (קריאה ראשונית ויצירת תוויות עזר)
   - `bibtex main` (עיבוד המקורות הביבליוגרפיים ב-IEEEtran)
   - `xelatex main.tex` (פתרון הפניות צולבות, עדכון תוכן עניינים ורשימת איורים)
   - `xelatex main.tex` (סגירת עימוד, כותרות עליונות ומספור עמודים סופי)

התוצר נוצר בנתיב `report/main.pdf` (**39 עמודים**).
